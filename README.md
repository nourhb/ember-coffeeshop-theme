# Ember — Coffee Shop Block Theme

**Ember** is a warm, cozy WordPress block theme built for coffee shops, cafés and roasteries. Espresso-brown and caramel tones, menu-board price lists with dotted leaders, roast stories, barista team profiles, brewing workshops and a visit-us block — everything a neighborhood café needs online.

## Features

- **Full Site Editing** — edit headers, footers, templates and every pixel with the block editor
- **Complete theme.json design system** — espresso/caramel/cream/sage palette, Fraunces display + Nunito Sans body type, fluid type scale, warm shadows
- **10 hand-built block patterns** — café hero, espresso bar menu, bakery case, roastery story, baristas team, photo gallery, regulars testimonials, visit-us hours/location, brewing workshops, newsletter CTA
- **"Matcha" style variation** — one-click fresh green alternative
- **Menu-board styling** — dotted price leaders, hover lift on menu items
- **Photo-rich by default** — real café photography wired into hero, gallery, roastery and visit patterns
- **Motion with manners** — steam accents, scroll reveals; all disabled under `prefers-reduced-motion`
- **Accessibility** — skip link, visible focus states, semantic landmarks
- **Translation-ready** — `ember` text domain

## Installation

1. Download or clone this repository.
2. Copy the `ember-coffeeshop-theme` folder into `wp-content/themes/`.
3. In WordPress, go to **Appearance → Themes** and activate **Ember**.
4. Open **Appearance → Editor** to customize templates, or insert any **Ember** pattern from the block inserter.

No plugins required. Google Fonts (Fraunces + Nunito Sans) load automatically; the theme works offline with system fallbacks.

## Customization

- **Colors & fonts:** everything flows from `theme.json` — tweak the palette, type scale or spacing there.
- **Style variation:** switch to the **Matcha** fresh-green style from the Site Editor's Styles panel.
- **Custom page template:** `page-wide.html` (1200px canvas) is registered as a page template.
- **Block styles:** Outline Caramel (button), Menu Card (group), Rounded Warm (image), Roast Note (quote), Menu Title (heading).
- **Front-end script:** `assets/js/theme.js` handles the back-to-top button and scroll reveals — vanilla JS, no dependencies.
